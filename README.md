## 🚀 Quick Start

### Requirements
- Node.js 18+
- Running ComfyUI service (default `http://127.0.0.1:8188`)

### Installation Steps

```bash
# Clone the project
git clone https://github.com/your-username/comfyflow-lite.git
cd comfyflow-lite

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to get started
